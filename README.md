 💪 FITLOG — Workout Library

Your workouts. Your plan. Your progress.

FITLOG is a modern workout library web application built with Next.js. It allows users to explore exercises, view detailed workout instructions, organize their daily workout plans, and save exercises for later. With a clean dark-themed interface and vibrant lime accents, FITLOG makes workout planning simple and organized.

 🚀 Technologies Used

- Next.js 16 — React framework for routing and application rendering.
- React — Component-based user interface.
- Tailwind CSS 4 — Utility-first styling.
- daisyUI 5 — Prebuilt UI components and theme customization.
- JavaScript (JSX) — Application logic and components.
- Context API — Shared state management for workout plans and saved exercises.
- FitLog Exercise API — Provides workout and exercise information.

 ✨ Key Features

1. 🏋️ Workout Library
Browse a collection of exercises with information such as muscle groups, equipment, difficulty level, duration, and estimated calories burned.

 2. 📋 Daily Workout Planner
Add exercises to your daily workout plan and organize your training session. The application limits the daily plan to five exercises.

 3. 🔖 Save Exercises for Later
Save your favorite exercises for future workouts and manage them separately from your daily plan.

 4. 📊 Workout Statistics and Sorting
View workout summaries, including total duration and estimated calories. Sort exercises by duration, calories burned, or rating.

 5. ✅ Workout Progress Tracking
Mark exercises as completed, remove exercises from your lists, and view detailed exercise instructions to help organize your workout routine.

 🛠️ Getting Started

 Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm
- Git

 Installation

1. Clone the repository**

bash
git clone https://github.com/ovidas109054/WorkOut_Library.git


2. Navigate to the project directory**

bash
cd WorkOut_Library


3. Install dependencies**

bash
npm install


4. Start the development server**

bash
npm run dev


5. Open the application**

Visit [http://localhost:3000](http://localhost:3000) in your browser.
